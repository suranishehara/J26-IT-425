# Synthetic garment reference collection

Fifteen separately generated product-reference images: five shirts, five blouses and five kurtas. Created with the built-in image-generation tool for local virtual try-on demonstrations. They are synthetic catalogue assets, not paired real-world training examples or evidence of model accuracy.

Use one PNG as the garment reference in the local app. Select Shirt / blouse / kurta. A full-length kurta may need a larger replacement region; current automatic upper-body masks may omit its lower hem.

The image specifications and shared prompt are documented in PROMPTS.md. These files do not include matching person or ground-truth try-on photographs.
